# 简历写作 Skill

## 触发方式

用户说"调用简历skill"、"/简历"、或"根据JD写一份简历"时，按以下流程执行。

---

## 一、执行流程

1. **读取JD**：提取目标岗位的核心要求、关键词、隐性需求
2. **匹配度分析**：对照用户背景（见第二节），列出匹配点和不匹配点
3. **定制策略**：决定每段经历的侧重点——突出什么、弱化什么、用什么动词
4. **生成简历**：按模板写作公式（见第三节）输出HTML
5. **自检**：用六步检查法（见第四节）逐条打勾

## 三、写作公式

### 3.1 简历整体结构
```
标题（姓名）
  ↓
岗位名称（主标题 + "/" + 副标题扩大匹配面）
  ↓
求职意向行（岗位 · 城市 · 可接受类型）  ← 必填，HR 3秒确认方向
  ↓
核心价值一句话（结论先行 + 双数字：总年限+成长速度 + 薪资轨迹3.5K→15K）
  ↓
KPI条（5个核心数据，必须有行业对比，对标JD选指标）
  ↓
工作经历（占50-70%，倒序，每段3-4条，每条≤2行）
  ↓
自我评价（3段：为什么是我 + 核心能力 + 管理可复制）
  ↓
项目速览（表格，5行以内）
  ↓
补充说明（解释空档期 + 表明岗位灵活性 + 作品集提示）  ← 必填
```

### 3.2 工作经历写作公式

```
【子标题：情境(S) → 量化结果(R)】{强动词}{负责什么}。{情境铺垫}，{通过什么方式(T+A)}，{取得什么量化成果(R)}
```

- 子标题格式：【困境 → 结果】——必须有对比才有冲击力
  - ✅ `【旧品复活：3个月未起量 → 月销千万】`
  - ❌ `【月销千万】旧品复活` （缺情境，看不出难度）
- 强动词库（按强度分级）：
  - **最高级**（带画面感）：逆转至、抢占XX蓝海、团队已放弃XX、从零搭建
  - **强级**：主导、发起、独立操盘、推动、建立、优化
  - **禁用**：参与、协助、负责（非不能用，但避免作为主要动词）
- 每条必须有"主动/率先/超出职责/从零搭建"中的至少一个（105%原则）
- 每条≤2行，排版略宽松优于过密
- 数据必须加粗
- 嵌入情境细节增强画面感：如"接手时团队已放弃该品"比"接手时未起量"更有力

### 3.3 自我评价写作公式

```
【为什么是我】X年经验 + X年内完成XX跃升 + 薪资轨迹（3.5K→15K）+ 跨品类+差异化定位
【核心能力】对标JD要求的能力 + 量化证据 + 行业对比
【管理可复制】从0搭建SOP + 团队复用证据 + 方法论可迁移
```

- 时间表述双数字策略：
  - 第一个数字 = 总经验年限（"4年内容操盘经验"）
  - 第二个数字 = 成长速度（"3年内完成设计师助理到项目主管的三级跃升"）
  - 两个数字各有功能，不要混用
- 必须嵌入薪资轨迹"3.5K→15K"——比"从执行到管理"更具象
- 禁止：性格形容词（勤奋、开朗、踏实）
- 允许：技能闪光点+场景+证据

### 3.5 补充说明模块

```
· 解释空档期（如"项目制合作结束后的择业过渡期，期间持续跟进XX"）
· 表明岗位灵活性（如"可接受品牌方或代理公司XX岗位，base XX"）
· 作品集提示（如"完整作品集视频素材可面试时展示"）
```

这个模块解决三个HR隐性担忧：空档期干什么了、是不是只能做一种岗位、有没有作品可以验证。

### 3.4 项目速览表格

```
| 项目 | 品类 | 角色 | 核心成果 |
```

选与JD匹配度最高的5个项目，不写JD不关心的。

## 四、八步检查法

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 首屏结论 | 打开第一句话能回答"你能解决什么问题" |
| 2 | 求职意向 | 标题下方有明确的"岗位 · 城市 · 可接受类型"行 |
| 3 | STAR完整 | 每条有情境(S)→行动(A)→结果(R)，子标题必须有"困境→结果"对比 |
| 4 | 三段式完整 | 每条有"通过XX方式"的过程描述 |
| 5 | 105%可见 | 至少一处出现"主动/率先/超出职责/从零搭建" |
| 6 | 动词分级 | 没有"参与""协助"，至少一处用最高级动词（逆转至/抢占蓝海/团队已放弃） |
| 7 | 排版密度 | 每条≤2行，整体留白略多优于过密 |
| 8 | 必需要素齐全 | 邮箱Outlook、求职意向行、薪资轨迹3.5K→15K、补充说明、作品集入口——五项缺一不可 |

## 五、JD匹配策略

### 投"项目主管/管理岗"
- 侧重点：带团队、定方向、SOP搭建、跨部门协调、对品牌方结果负责
- 关键词：团队管理、SOP、流程搭建、组长、带教、复盘机制
- 弱化：纯执行内容（拍摄、剪辑、设计）

### 投"内容负责人/内容策略"
- 侧重点：爆款方法论、品类迁移、数据驱动、多平台策略
- 关键词：爆款率、全域投放、脚本分层、A/B测试、品类研究
- 弱化：管理规模（3人团队不大，不主动提人数）

### 投"品牌方内容岗"
- 侧重点：合诚经验（品牌方视角）、从0到1、视觉资产管理、长期深耕
- 关键词：品牌内容体系、多平台、视觉库、搜索率、近3年
- 弱化：投放消耗数据（品牌方不看重这个）

## 六、面试官敏感词清单（可删或弱化）

根据大厂面试官分享，以下内容容易被追问或质疑：
- 精确投放数据（改用"百万级""千万级"）
- 团队人数（3人团队不大，投大公司时不主动提人数）
- 跳槽频率（三段经历要串成成长叙事）
- "优秀毕业生""国家奖学金"（专科背景这些词反而引起学历追问）

## 七、输出格式

生成干净的HTML简历文件，要求：
- A4尺寸，两栏布局（左窄右宽）
- 深色侧边栏放联系/技能/教育
- 白色主区域放经历/数据/评价
- 打印时自动适配（@media print）
- 支持精确版/脱敏版切换

文件命名：`范思静-简历-{目标岗位}-{日期}.html`
